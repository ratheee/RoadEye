# RoadEye
Real-Time Vehicle and Pedestrian Detection with Collision Alerts  Overview This project is a driver assistance system that processes live video to detect vehicles and pedestrians on the road, estimates how far each one is from the camera, and warns the driver when an object enters an unsafe range. It aims to reduce accidents caused by delayed driver reaction.  Key Features - Real-time detection of vehicles and pedestrians using YOLOv9 - Distance estimation for each detected object from a single camera - Visual and audio alerts when an object crosses a safety threshold - Web interface showing the live feed with bounding boxes and distances - Support for webcam input and pre-recorded video files  Tech Stack - Language: Python - Detection model: YOLOv9 (pretrained, PyTorch) - Video processing: OpenCV - Backend: Flask - Frontend: HTML, CSS, JavaScript  How It Works 1. The system captures frames from a camera or video file. 2. Each frame is passed to the YOLOv9 model, which returns the    detected objects with bounding boxes and confidence scores. 3. The distance of each object is estimated from its bounding box    size and the camera's focal length. 4. If the distance falls below a set threshold, an alert is triggered. 5. The annotated frame is streamed to the web interface in real time.
